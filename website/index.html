Project Overview

This project was developed as part of the Operating Systems course. The objective is to design and program an autonomous robot capable of navigating an arena, detecting obstacles or resources, and executing a predefined strategy.

The robot is built using a LEGO Mindstorms platform and programmed in C under a Linux-based environment. The software architecture follows a modular design separating hardware control from high-level decision making.

Robot Architecture

Hardware

The robot is based on a differential drive system with two independently controlled wheels. A vertical mechanical structure is used to push or transport resources. Sensors (ultrasonic and/or color) provide information about the environment.

Software

  • main.c – Program entry point and control loop
  • movement.c – Low-level motor control
  • sensors.c – Sensor access and abstraction
  • strategy.c – High-level robot behavior

Algorithms and Strategy

The robot operates autonomously using a continuous control loop:

while robot is running:
    read sensors
    if obstacle or resource detected:
        react (turn, stop, activate mechanism)
    else:
        move forward

The strategy prioritizes simplicity and robustness to ensure reliable behavior during the competition.

Usage Instructions

Compilation

make

Execution

./robot

Ensure that all motors and sensors are properly connected before running the program.

Development Process

The project was developed collaboratively using GitLab for version control. Each team member contributed code and documentation, with regular testing performed directly on the robot.
